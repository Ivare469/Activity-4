# Typhoon-Ready Household Guide

Educational demo prototype (Disaster Risk Reduction / Climate Change Adaptation).
No live warnings, forecasts, or official advisories. Demo data only.

## Workflow
1. Run each prompt from prompt-log.md in GitHub Copilot Chat.
2. Save the generated files in the matching outputs/ subfolder BEFORE running the next experiment.
3. Copy the best final version of index.html, styles.css, script.js into the project root.
4. Fill in the Observation, Verification, and Reflection fields in prompt-log.md.
5. Push to GitHub and import into CodeSandbox; paste both links below.
